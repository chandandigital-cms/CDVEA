# cdvea-blender

Resolve the plugin root two directories above this file. Keep sources intact and follow the user’s current scope.

Blender is an optional external application, not a bundled renderer. Check `blender --version` only if it is available. Use [the Blender Python API](https://docs.blender.org/api/current/) matching the installed version for scene scripts. Use this route for requested 3D assets, camera animation, rendered titles or an existing .blend project.

Render a low-sample frame and a short range first. Match the edit’s frame rate, dimensions, alpha and colour transform. Deliver the .blend file and required assets with any renders. A skill does not supply a 3D model, camera track or native application connection. Report missing inputs and keep final footage editing in the CDVEA editor. No Blender render test has run for this release.
