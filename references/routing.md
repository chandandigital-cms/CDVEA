# Choose a CDVEA workflow

Paths start at the plugin root. Load only the needed workflow. Resolve vendor technical links from their own directories.

| Skill | Purpose |
| --- | --- |
| [cdvea](../skills/cdvea/SKILL.md) | Plan and complete video editing jobs across CDVEA footage, audio, caption, motion and delivery tools. |
| [cdvea-ai-assist](../skills/cdvea-ai-assist/SKILL.md) | Run optional local speech transcription and scene detection, or plan model-based restoration. |
| [cdvea-audio](../skills/cdvea-audio/SKILL.md) | Clean speech, sync cameras, mix music and effects, and measure final loudness. |
| [cdvea-audio-polish](../skills/cdvea-audio-polish/SKILL.md) | Polish short-form audio joins, crossfades and loudness. |
| [cdvea-auto-cut](../skills/cdvea-auto-cut/SKILL.md) | Suggest cuts and split recordings while preserving speech boundaries. |
| [cdvea-blender](../skills/cdvea-blender/SKILL.md) | Plan Blender 3D scenes, tracked composites and animated assets for a video edit. |
| [cdvea-broll](../skills/cdvea-broll/SKILL.md) | Find and place B-roll, supporting shots shown during speech, with source and rights records. |
| [cdvea-colour](../skills/cdvea-colour/SKILL.md) | Correct exposure, white balance and shot matching; manage LUTs, HDR and SDR delivery. |
| [cdvea-delivery](../skills/cdvea-delivery/SKILL.md) | Review exports, create proxies and hand over masters, captions and editable cut lists. |
| [cdvea-edit-plan](../skills/cdvea-edit-plan/SKILL.md) | Build and render a local clip assembly with explicit source ranges, speed and output timing. |
| [cdvea-hook-overlay](../skills/cdvea-hook-overlay/SKILL.md) | Make readable hook and title plates for social clips. |
| [cdvea-html-motion](../skills/cdvea-html-motion/SKILL.md) | Author HTML motion graphics, titles, explainers and overlays with optional HyperFrames. |
| [cdvea-html-render](../skills/cdvea-html-render/SKILL.md) | Preview, inspect and render existing HyperFrames video projects. |
| [cdvea-indic-captions](../skills/cdvea-indic-captions/SKILL.md) | Prepare, retime and review Bengali, Hindi and English subtitles and styled captions. |
| [cdvea-loops](../skills/cdvea-loops/SKILL.md) | Make loops, GIFs and transparent stickers with local media tools. |
| [cdvea-media-assets](../skills/cdvea-media-assets/SKILL.md) | Prepare video, audio and image assets for a HyperFrames composition; check provider and local options. |
| [cdvea-motion-components](../skills/cdvea-motion-components/SKILL.md) | Find reusable HyperFrames blocks and components for requested motion designs. |
| [cdvea-product-video](../skills/cdvea-product-video/SKILL.md) | Make product demos and narrated promos from real footage, screenshots, voice and music. |
| [cdvea-reference-analysis](../skills/cdvea-reference-analysis/SKILL.md) | Analyse shots, pacing, camera movement, sound and titles in a supplied reference video. |
| [cdvea-render-qc](../skills/cdvea-render-qc/SKILL.md) | Check output media and create proof sheets for render review. |
| [cdvea-restoration](../skills/cdvea-restoration/SKILL.md) | Stabilise, denoise, deinterlace, repair containers and prepare optional AI restoration jobs. |
| [cdvea-screen-demo](../skills/cdvea-screen-demo/SKILL.md) | Plan and edit browser or software demos with real screen recordings and callouts. |
| [cdvea-short-workflow](../skills/cdvea-short-workflow/SKILL.md) | Plan a short-form edit using the bundled auto-cut, hook, caption and quality review helpers. |
| [cdvea-social](../skills/cdvea-social/SKILL.md) | Make platform variants, highlights, ad edits and thumbnails from a reviewed master. |
| [cdvea-storyboard](../skills/cdvea-storyboard/SKILL.md) | Plan stories, shot lists and sound cues for adverts, weddings, tutorials and product films. |
| [cdvea-vfx](../skills/cdvea-vfx/SKILL.md) | Composite footage, green screens, masks, picture-in-picture, overlays and transparent graphics. |
| [cdvea-word-captions](../skills/cdvea-word-captions/SKILL.md) | Transcribe locally and create timed word captions with optional faster-whisper. |
| [cdvea-workbench](../skills/cdvea-workbench/SKILL.md) | Edit complex timelines with multi-track compositing, motion graphics and validated FFmpeg render plans. |
| [cdvea-youtube](../skills/cdvea-youtube/SKILL.md) | Prepare or explicitly upload a finished video to YouTube using the user\u2019s account and OAuth setup. |
| [ffmpeg-skill](../skills/ffmpeg-skill/SKILL.md) | Run the bundled 42 typed FFmpeg tools for measured local cuts, captions, colour, sound, multicam and exports. Use CDVEA for editorial decisions and workflows. |
